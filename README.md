# Hello Repository

This repository contains sample text files for learning purposes.

## How to Download Files

There are several ways to download files from this repository:

### Method 1: Clone the Entire Repository

Clone the repository to get all files:

```bash
git clone https://github.com/Sumitkr394/hello.git
cd hello
```

### Method 2: Download Individual Files via GitHub Web Interface

1. Navigate to the file on GitHub (e.g., `work1.txt` or `new.txt`)
2. Click the **Raw** button
3. Right-click on the page and select **Save As** to download the file

### Method 3: Download Using wget

Download a specific file using wget:

```bash
wget https://raw.githubusercontent.com/Sumitkr394/hello/main/work1.txt
```

### Method 4: Download Using curl

Download a specific file using curl:

```bash
curl -O https://raw.githubusercontent.com/Sumitkr394/hello/main/work1.txt
```

### Method 5: Download Repository as ZIP

1. Go to the repository page on GitHub
2. Click the green **Code** button
3. Select **Download ZIP**
4. Extract the ZIP file to access all files

### Method 6: Download via GitHub CLI

If you have GitHub CLI installed:

```bash
gh repo clone Sumitkr394/hello
```
